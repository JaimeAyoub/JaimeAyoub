## Featured projects

### 🖌️ [Fightink](https://github.com/JaimeAyoub/TesisPeroAhoraEnUnreal) · Unreal Engine 5
My thesis project: a hack and slash where every hit looks like a brushstroke. I built the Sumi-e style VFX (Niagara), materials, combat system and UI. Defeat enemies to collect the ink you need to get through each level.

### ⛪ [Excriblecism](https://github.com/JaimeAyoub/Exorcist) · Unity
A team-made horror/action game where you play as an exorcist and fight demons by typing prayers. I was the **game director** and worked on combat VFX and shaders, object interaction, combat logic and SFX.

### 🚀 [Don't download RAM from the internet](https://github.com/JaimeAyoub/StarFoxUnreal) · Unreal Engine 5
You're a virus inside a PC, taking down the ships that protect the computer.
